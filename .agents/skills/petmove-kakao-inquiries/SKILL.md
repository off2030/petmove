## 범위와 저장 위치
- 고객이 보낸 서류·사진을 펫무브워크에 보관하는 실무 요청은 [카카오 서류 저장 스킬](../petmove-kakao-documents/SKILL.md)을 사용한다.
- 문의 수집만 수행한다. 네이버 임시저장·답변 작성·태그·링크 카드·발행은 하지 않는다. 블로그 글쓰기와 예약 발행은 별도 `petmove-naver-post` 스킬의 단계다.
- 저장소 루트를 기준으로 `work/naver-inquiries/pending/`에 문의별 UTF-8 `.txt` 파일을 저장하고 `work/naver-inquiries/index.json`에서 원본과 처리 상태를 관리한다. 특정 PC의 절대 경로에 고정하지 않는다.
- `published/`는 예약 발행과 저장본 검증이 완료된 문의 보관용이다. 수집 시 이 폴더로 옮기지 않는다.
- 먼저 `/work/naver-inquiries/`가 Git에서 제외되는지 확인한다. 고객 문의 원문·관리 정보·첨부파일·로그인 정보는 스킬이나 Git에 넣지 않는다.

## 기준점과 중복 방지
1. 현재 대기열과 완료 파일, 기존 네이버 임시저장 문의의 원본 기록을 확인해 같은 문의를 다시 수집하지 않는다.
2. 펫무브 카카오비즈니스의 `채팅` → `중요채팅 목록` 맨 위 문의를 시작 기준점으로 삼고 **그 문의 자체를 포함**한다. 그 이전 문의는 기존 작업분으로 제외한다. 특정 고객명이나 날짜로 기준점을 고정하지 않는다. 같은 기준점으로 이어서 수집할 때는 로컬 색인의 처리된 원본을 건너뛴다.
3. 기준점부터 이후 상담을 날짜순으로 검토해 요청한 수만큼 적합한 문의를 고른다. 수량이 없으면 작업할 수를 확인한다. 채팅 목록 날짜는 마지막 대화일이므로 채팅 안에서 실제 질문 날짜를 확인한다. 기준일 이전부터 이어진 방이라도 기준 이후 새 질문이 있으면 그 질문과 필요한 배경만 사용한다.
4. 날짜 필터는 검색 보조 수단이다. 기간을 검색했다는 이유로 그 기간 전체가 검토 완료됐다고 기록하지 않는다. 확인한 원본별로 선택·제외·재검토 여부를 관리하며, 보지 않은 대화를 건너뛰는 완료 지점을 만들지 않는다.

## 문의 선별과 다듬기
- 질문은 주로 채팅 초반에 있으므로 초반을 중심으로 읽고 뒤 대화는 필요한 조건을 보완할 때만 참고한다.
- 단순 인사·감사, 광고, 예약·입금·배송 확인, 검사 결과 통보 등 블로그 답변용 문의가 아닌 내용은 제외한다. 다른 고객의 대화를 합치지 않는다.
- 한 상담의 여러 메시지에 흩어진 상황과 질문을 하나의 자연스러운 문의로 정리한다. 오타·띄어쓰기는 고치되 동물 종류·나이·품종·체중·이동 경로·기존 준비 이력·질문 의도는 보존한다. 없는 동물 종류나 검사 결과를 만들지 않는다.
- 상담자가 설명한 절차나 결과를 고객이 이미 한 사실로 바꾸지 않는다. 고객이 잘못 알고 있는 전제는 답변할 쟁점으로 남긴다.
- 비용만 묻는 짧은 문의는 원래 맥락 안에서 절차·준비기간 등의 질문을 조금 보탤 수 있다. 문의가 충분하면 늘리지 않는다.
- 오래된 달력 날짜는 미래의 자연스러운 표현이나 상대 기간으로 정리할 수 있다. 다만 ‘다음 달 출국’, ‘채혈 후 4~5개월’처럼 준비기간이 핵심이면 그 간격을 유지하며 충분한 기간으로 바꿔 문제를 없애지 않는다. 각색한 내용을 관리용 메모에 남긴다.
- 공개용 질문에서는 고객명·연락처·상세 주소·예약번호·결제정보를 제거한다. 상담자의 답변과 과거 견적 금액을 질문에 넣지 않는다.

## 파일과 확인
- 기존 번호에 이어 고유 문의 번호를 부여한다. 파일에는 번호, 상태, 실제 원본 문의일, 원본 채팅 URL, 구분 가능한 제목, `[공개용 문의]`와 다듬은 질문을 기록한다. 날짜 각색 등 필요한 관리 메모는 공개용 질문과 분리한다.
- `index.json`에는 원본별 처리 상태와 파일 위치를 기록한다. 원본 URL 하나에 독립적인 새 문의를 여러 개 수집하면 문의 날짜·구간도 함께 구분해 중복을 막는다.
- 저장 후 요청한 수와 실제 파일 수, 원본 중복, 질문 누락, 개인정보 제거 여부를 확인한다. 완료 보고에는 저장 위치와 수량을 알린다.
- 카카오톡 메시지 전송, 중요 표시 이동·해제, 상담 상태 변경은 수집 권한에 포함되지 않는다.
