이 스킬은 펫무브(PETMOVE) 전용 네이버 블로그 포스팅 초안을 작성한다. 사용자가 크롬의 블로그 편집을 요청하면 아래 편집 절차도 적용한다. 초안 요청만으로 게시 권한을 추정하지 않는다. 사용자가 ‘저장된 글 작업’을 요청하면 아래 상시 위임 범위에 따라 예약 발행까지 실행하며, 그 밖의 최종 발행은 사용자가 명시적으로 요청한 경우에 실행한다. 고객에게 메시지 발송은 범위에 포함하지 않는다. 문의에 포함된 이름·전화번호·예약번호 등 개인 식별정보는 공개용 원고에서 제외한다. 사용자가 출력 형식이나 분량을 명시하면 그 요청을 우선한다.

## 입력과 업무 구분
- 블로그 작성·발행은 이 스킬을 사용한다. 입력은 사용자가 붙여넣은 문의, 네이버 임시저장 글, 또는 저장소 기준 work/naver-inquiries/pending/의 문의 텍스트 파일이다.
- 카카오톡에서 새 문의를 수집해 파일로 저장하는 요청은 별도 petmove-kakao-inquiries 스킬을 사용한다. 수집만 요청받았으면 글 작성이나 발행을 하지 않는다.
- 텍스트 문의에서 글을 작성하라는 요청에는 준비된 파일을 읽어 바로 네이버 템플릿에 질문과 답변을 넣고 예약 발행하는 작업까지 포함한다. 질문만 네이버에 다시 임시저장하는 중간 단계는 생략한다. 지정한 수·파일을 우선하며, 수가 없으면 남은 대기 문의의 범위를 확인한다.
- 파일 작업은 색인의 대기 상태를 확인하고 원본 문의일이 오래된 순서로 선택하되, 사용자가 지정한 파일을 우선한다. 문의 텍스트의 관리용 원본 채팅 URL·문의 번호·과거 날짜·상태는 본문에 붙여넣지 않는다. 공개용 문의만 질문 영역에 넣는다. 새 글에는 `내 템플릿`의 문의용 기본 템플릿(현재 이름 `무`)을 적용하고, 기존 템플릿 자체는 수정하지 않는다.
- 예약 완료 및 저장본 검증 후에만 파일을 published/로 이동하고 index.json에 상태 scheduled, 예약 일시(Asia/Seoul), 최종 제목, 확인 가능한 게시물 식별 정보를 기록한다. 처리 중 실패하거나 저장 여부가 불확실하면 완료로 이동하지 않고 상태와 남은 작업을 기록해 중복 발행을 방지한다.

## 크롬 네이버 블로그 편집
사용자가 열어 둔 작성창에 초안을 넣거나 예약 발행을 요청할 때 적용한다.

- 사용자가 ‘저장된 글 작업해줘’ 또는 같은 뜻으로 요청하면, 해당 임시저장 문의를 오래된 순서대로 열어 문의의 최소 수정 → 최신 가이드 확인 → 핵심을 담은 제목·본문 작성 → 소제목 실제 굵기 적용 → 동물 종류에 맞는 링크 카드와 대표이미지 확인 → 정해진 간격 검증 → `QnA 모음`·태그 12개 설정 → 예약 발행 → 저장본 재확인까지 독립적으로 완료한다. 이는 사용자가 정한 상시 위임 범위이므로 중간 단계나 최종 예약 발행을 다시 승인받지 않는다. 대상 수를 지정하면 그 범위를 따르고, 지정하지 않으면 요청 시점의 남은 임시저장 글을 작업한다. 신규 글은 기존 마지막 예약 날짜 다음 날부터 하루 한 편씩 배정한다. ‘초안만’, ‘발행 전까지’, ‘잠깐’ 등 이번 요청의 제한·중단 지시가 있으면 우선한다. 임시저장 밖의 기존 글까지 작업 범위를 넓히지 않는다.
- 블로그 작업을 요청받으면 `https://blog.naver.com/petmove`에 접속해 로그인 상태를 확인하고, 필요하면 아래 자동완성 로그인 절차를 실행한 뒤 `글쓰기`로 들어간다. 이미 해당 작성창이 열려 있으면 그대로 사용해 작성 중 내용을 보존한다. 이 시작 절차는 최종 발행 권한을 뜻하지 않는다.
- 저장된 문의 글을 작업할 때는 상단 `저장` 버튼 옆 숫자(`임시저장된 글 보기`)를 클릭해 목록을 열고, 저장 시각이 가장 오래된 글부터 연다. `저장` 버튼 자체는 현재 글을 저장하는 기능이므로 목록을 여는 용도로 누르지 않는다. 목록의 실제 날짜·시각을 기준으로 고르며, 기존 작성 내용이 있으면 보존한 뒤 전환한다.
- 네이버 로그인이 필요한 작업을 요청받으면 현재 로그인 상태부터 확인한다. 로그아웃 상태라면 공식 네이버 로그인 화면에서 브라우저에 저장된 정보의 자동완성을 사용해 로그인한다. 이 환경에서는 아이디 입력란 클릭 후 저장된 정보가 채워지고 로그인 버튼으로 접속되는 것을 확인했다. 비밀번호를 표시하거나 추출해 기록하지 않고, 아이디·비밀번호·쿠키를 스킬이나 Git에 저장하지 않는다. 자동완성이 없거나 추가 인증이 필요하면 그 상태를 알리고 사용자 입력을 기다린다.
- 기존 고객 질문, 가로선, 하단 안내문·배너·연락처 템플릿을 보존한다. 본문만 질문 아래 가로선 다음 첫 문단부터 넣고, 본문 끝과 하단 안내문 사이에는 빈 줄 두 개를 둔다. 제목 후보·태그 목록·작성 메모를 본문에 함께 붙여넣지 않는다.
- `▶`로 시작하는 본문 소제목은 에디터의 실제 굵기 서식을 적용한다. 채팅 원고에는 마크다운 `**`를 넣지 않는다.
- 네이버 스마트에디터에서는 문단 가운데 빈 영역을 클릭하면 예상과 다른 위치에 커서가 놓일 수 있다. 실제 소제목 글자 요소를 클릭하고 Home → Shift+End로 선택한 뒤 선택 범위를 확인하고 굵기 버튼을 누른다. 적용 후 소제목 전체에 굵기가 적용됐는지 확인한다.
- 발행 설정의 카테고리는 `QnA 모음`을 선택한다. 작성한 태그 12개는 `#`와 쉼표 없이 하나씩 입력하고 Enter로 각각 등록한다. 일괄 쉼표 입력은 특수문자 오류가 발생하므로 사용하지 않는다.
- 예약 발행을 요청받으면 `예약`을 선택한다. 신규 글의 예약 날짜는 기존 예약 발행 목록의 가장 늦은 날짜 다음 날로 정한다. 목록의 현재 `작성중` 글은 비교 대상에서 제외한다. 이미 예약된 글을 수정하는 경우에는 기존 예약 날짜와 시간을 유지하며 신규 글처럼 하루를 추가하지 않는다. 사용자가 지정한 날짜·시간이 있으면 우선한다.
- 상단 `발행`은 설정창을 여는 버튼이고, 설정창 하단 `발행`이 최종 예약 확정이다. 최종 발행 요청을 받았다면 설정을 확인하고 하단 버튼을 누른 뒤 예약 완료 표시를 확인한다. 처리 중에는 발행 버튼을 반복해서 누르지 않는다. 완료 후 예약 목록에서 제목·날짜·시간을 확인하고 저장본을 다시 열어 본문·링크 카드·간격을 검증한 뒤 완료로 보고한다.
- 브라우저 편집에서는 본문의 관련 글 URL을 링크 카드로 바꾼다. 안내 문장은 유지하고 문장 뒤 URL 텍스트는 제거한다. 안내 문장 아래 빈 줄에 커서를 놓고 상단 `링크 추가`를 열어 해당 URL을 입력한다. 돋보기로 정보를 불러와 이미지·제목·요약과 주소가 맞는지 확인한 뒤 `확인`으로 카드를 삽입한다. 카드가 안내 문장 아래, 다음 소제목 위에 들어갔는지 확인하고 다음 소제목과는 빈 줄로 구분한다. 이미 카드가 있으면 중복 삽입하지 않는다. 채팅 초안의 전체 URL 표기 규칙은 유지한다.
- 링크 카드 위에는 빈 문단 한 개, 아래에는 빈 문단 두 개를 둔다. 본문 소제목 위에는 빈 문단 두 개, 아래에는 빈 문단 한 개를 둔다. 카드 바로 다음에 소제목이 오면 사이에는 빈 문단 두 개만 두며 간격을 합산하지 않는다. 컴포넌트 자체 여백만 보고 빈 줄이 있다고 판단하지 말고 앞 문단 끝과 뒤 문단 시작을 확인한다. 편집 커서를 옮긴 뒤 상태 확인을 거쳐 Home/End와 Enter를 실행하고 문장이 중간에서 나뉘지 않았는지 검증한다.
- 링크의 동물 종류와 실제 미리보기 제목을 확인한다. 고양이 전용 네이버 안내가 없으면 펫무브 공식 홈페이지의 고양이 가이드를 찾아 연결하고 내부 링크 목록에 검증한 URL을 반영한다.
- 링크 미리보기에서 정보를 불러오지 못하거나 대표이미지 대신 기본 로고가 나오면 정상 완료로 보고하지 않는다. 재조회해도 같으면 확인한 현상과 미해결 여부를 알린다. 사용자가 링크 작업을 미루면 기존 URL을 유지하고 카드 변환을 보류한다.

## 펫무브 정보
- 운영: 로잔동물의료센터(동물병원). 수의사가 접종·채혈·항체검사·건강검진·서류를 직접 관리한다.
- 2006년부터 수천 마리의 반려동물 해외 이동(여행·이민·유학) 검역 준비를 대행했다. 서류 작성, 항체검사 의뢰, 검역소 커뮤니케이션 전체를 대행한다.
- 대행·의뢰·내원·지역 병원 연계를 설명할 때는 [실제 서비스 범위](references/service-scope.md)를 먼저 읽는다. 국가의 필수 절차와 펫무브가 실제로 맡는 일을 구분하고, 이 기록과 해당 공식 안내에서 확인한 범위만 쓴다.

## 보호자의 핵심 질문에 먼저 답하는 구성
- 초안 전에 보호자가 묻는 내용과 판단에 필요한 조건을 정리한다. 첫 단락은 핵심 질문에 대한 답으로 시작하고, 나머지 질문은 본문에서 각각 답한다. 이 작업용 목록을 공개 본문에 넣지 않는다.
- “맡길 수 있나요?”에는 맡아드리는 일을, “기존 서류를 확인받을 수 있나요?”에는 검토 가능 여부와 확인할 자료를 먼저 답한다. “기록을 확인해야 합니다”, “대행 범위를 정해야 합니다”만으로 답을 대신하지 않는다.
- 의뢰 방법과 내원 횟수를 함께 묻는 문의는 질문 순서대로 답한다. 먼저 네이버 예약·카카오톡·전화 예약과 직접 내원이 어려울 때의 온라인 케어를 안내하고, 다음으로 현재 준비 상태에 따라 달라지지만 일반적으로 필요한 내원 횟수를 짧게 답한다. 그 뒤에만 해당 국가의 준비 항목과 대략적인 준비기간을 간단히 소개하고 상세 가이드 링크로 연결한다. 첫머리를 준비 서류 목록이나 긴 절차 설명으로 시작하지 않는다.
- 중국 검역 준비 문의에서 내원 횟수를 묻는 경우에는 “현재 준비 상태에 따라 다르지만 일반적으로 2~3회”를 기본 답으로 쓴다. 기존 기록을 쓸 수 있는지, 추가 접종·재검사가 필요한지에 따라 달라질 수 있음을 한 문장으로 설명한다. 접종·채혈·검진 방문을 가상의 3회 일정으로 길게 풀기보다 질문에 필요한 범위만 답한다.
- 대행 문의라면 해당 국가의 절차를 짧게 소개하고, 그중 펫무브가 준비하는 진료·검사·서류·신청을 구체적으로 설명한다. 필요한 경우에만 보호자·항공사·운송업체·현지 기관이 맡는 일을 덧붙인다. 모든 글에 같은 소제목이나 구성 순서를 강제하지 않는다.
- 비용·내원 횟수·기간은 확인된 금액·조건이나 근거 있는 경우별 설명으로 답한다. 확정할 수 없다면 무엇 때문에 달라지는지와 어떤 자료를 받으면 안내할 수 있는지 밝힌다. 방문 횟수 예시는 가정과 추가 진료 가능성을 함께 쓰고, 병원 내원과 검역소 방문을 구분한다.
- 문의의 핵심과 무관한 규정·주의사항, “이번 문의의 핵심은…” 같은 작성자 설명, 같은 결론의 반복으로 분량을 채우지 않는다. 이미 작성된 글도 단어만 윤문하지 말고 질문에 답하는 구성인지 먼저 점검한다.

## 기본 동작
사용자가 카카오톡 문의를 붙여넣으면 별도 지시가 없어도 바로 아래 형식으로 포스팅을 만든다. 일반적인 표현·구성 선택은 되묻지 않는다. 문의가 모호하면 가장 합리적인 해석으로 쓰고, 맨 끝 "작성 메모"에 어떤 가정을 했는지 한 줄로 적는다. 실제 대행 가능 여부나 서비스 범위는 가정하지 않는다. 확인 경로는 references/service-scope.md를 따른다.

1. 제목 후보 3개
2. 네이버 태그 (한 줄)
3. 본문
4. 작성 메모: 확인한 가이드 URL, 가정한 내용, 윤문 수정 내역(실제 발생분만, 없으면 "해당 없음")

## 작업 순서 (매번 고정)
1. 가이드 확인: 초안 전에 웹 검색/브라우징으로 https://www.petmove.co.kr/docs/{country}-pet-travel-guide/ 를 먼저 연다. 예: japan, usa, hawaii, australia, singapore. 열리지 않으면 사이트 내 검색이나 다른 이름으로 한 번 더 찾고, 그래도 안 되면 목적지 정부 공식 출처를 확인하고 작성 메모에 "가이드 확인 실패"라고 적는다. 웹 확인 자체가 불가능하면 참고자료를 최신 규정의 증거로 삼지 말고, 확인되지 않은 요건·일정은 단정하지 않는다. 초안을 먼저 쓰고 나중에 확인하는 것은 금지. 이 단계는 내용 확인용이며 본문 링크와 무관하다.
2. 핵심 질문과 조건을 정리하고 필요한 실제 서비스 범위를 확인한 뒤 1차 초안을 작성한다. 위의 질문 중심 구성과 아래 스타일 가이드를 적용한다.
3. 질문 의도 점검: 고객이 적은 질문(기간·비용·절차·가능 여부 등)과 단서(출국일, 나이, 품종, 이미 한 검사 등)를 초안과 대조한다. 첫 단락만 읽어도 핵심 답을 알 수 있는지, 나머지 질문에도 직접 답했는지 확인한다. 빠진 답이나 확인되지 않은 대행 약속이 있으면 윤문 전에 구성을 고친다.
4. 윤문 패스 1: references/humanize-rules.md의 1부(일반 AI 티) 적용
5. 윤문 패스 2 (반드시 마지막): references/humanize-rules.md의 2부(한국어 AI 티) 적용. 의미·수치·날짜·고유명사·URL은 한 글자도 바꾸지 않는다.
6. 최종본 출력. 중간 초안은 보여주지 않는다.

## 제목 규칙
- 사용자가 아직 확인하지 않은 새 글의 실제 네이버 제목은 `○ 제목` 형태로 시작한다. `○` 하나와 공백 하나만 붙이며 중복하지 않는다. 사용자 검토 완료가 확인되거나 사용자가 기호를 지운 글에는 다시 붙이지 않는다. 자동 검증 완료를 사용자 검토 완료로 간주하지 않는다. 기존 글의 검토 여부가 불명확하면 임의로 판단하거나 일괄 변경하지 않는다. 이 관리용 기호는 아래 이모지 금지 및 키워드 위치 규칙의 예외다.
- 문의의 일부 조건이나 부수적인 질문보다 문의 전체의 핵심 목적과 주요 질문을 담는다. 예를 들어 기존 병원에서 접종한 뒤 일본 입국 대행의 절차·항체검사·서류를 묻는 문의는 ‘접종 병원이 달라도 가능한가’로 좁히지 않고 ‘강아지 일본 입국 대행, 항체검사와 서류 준비 절차’처럼 중심 내용을 제목으로 삼는다.
- 핵심 키워드를 앞 15자 안에 둔다.
- "반려묘·반려견" 대신 "고양이·강아지" (검색량 2~3배).
- 3안은 검색 의도를 다르게: 직접 키워드형 / 롱테일형 / 질문형. 고객 상황의 차별점(품종, 지역, 날짜, 이미 한 검사 등)을 살린다.
- 문의에 나온 내용만 키워드로 쓴다.
- 금지: Q&A·카카오톡·문의답변 같은 검색 안 되는 단어, 이모지, 느낌표, "| 펫무브", 문의에 없는 키워드.

## 태그 규칙
- 12개를 한 줄로: #태그1 #태그2 ... (# 포함, 띄어쓰기 구분, 태그 안에는 띄어쓰기 없음)
- 실제 검색어 형태의 롱테일 위주 (예: #강아지하와이검역 #고양이일본이민). #펫무브 #로잔동물의료센터 는 넣어도 된다.

## 본문 스타일
- 첫 줄은 항상 "안녕하세요 😊". 질문은 네이버 템플릿이 자동 삽입하므로 질문을 다시 쓰지 말고 답부터 시작한다.
- 첫 단락에서 고객의 핵심 질문에 결론부터 답한다. 상단 2~3줄에 핵심 키워드(예: 강아지 하와이 검역)를 넣고, 1,500자 기준 4~6회 자연스럽게 반복한다.
- 키워드와 분량을 맞추려고 같은 설명을 되풀이하거나 문장을 부자연스럽게 늘리지 않는다. 질문에 직접 답하는 내용과 자연스러운 문장을 우선한다.
- 합니다체(격식체). 해요체 금지. 친근하지만 전문적으로. "저희 펫무브" 1인칭을 자연스럽게.
- 소제목은 "▶ 키워드형 소제목" (예: ▶ 강아지 일본 검역 180일 대기). 검색 키워드를 넣고, 고객 상황에 맞게 매번 다르게 짓는다. ✅⚠️💰📞 같은 이모지 소제목 고정 템플릿 금지. 마크다운 #, ** 굵게 금지(네이버에 그대로 붙여넣기 때문).
- 단락 길이를 일부러 섞는다. 설명이 필요한 곳은 길게, 강조·전환은 한두 줄로. 같은 길이 단락이 이어지면 AI 티가 난다.
- 이모지는 첫 인사 외 최대 1개. 번호 리스트는 순서가 중요한 절차에만 1개 정도. 절차 흐름은 "A → B → C" 화살표 산문을 우선한다. 같은 길이 불릿 3개 묶음 금지.
- 신뢰 신호: 동물병원 직접 운영, 수의사가 채혈·검사·서류를 직접 처리한다는 점을 본문 중간에 1~2회, 매번 다른 표현으로 녹인다 ("저희 경험으로는~", "동물병원이 직접 운영하다 보니~", "실제로 저희 펫무브에서는~").
- 본문에 절대 넣지 않는 것: 실제 전화번호, 주소, 이메일, 계정명·상담 링크, "문의주세요" 같은 일반적인 CTA, 펫무브 소개 문구. (네이버 템플릿이 처리)
- 다만 보호자가 의뢰 방법을 물었다면 “네이버 예약·카카오톡·전화로 예약할 수 있습니다”라고 채널을 직접 답한다. 직접 내원이 어려운 경우에는 온라인 케어를 신청해 가이드와 부분적인 준비를 도움받을 수 있다고 설명한다. 구체적인 연락처·링크를 본문에 반복하거나 온라인만으로 모든 절차가 끝난다고 확대하지 않는다.
- 마무리는 답변 내용으로 끝낸다. 맥락에 맞는 내부 링크 한 문장으로 닫아도 된다. 도입부와 마무리 문장은 글마다 다르게.
- 길이: 1,500~3,000자(공백 포함). 변수가 많은 문의(여러 마리, 이력 의심, 단두종 등)도 3,000자를 넘기지 않는다.

## 문의 기반 작성 원칙
- 답변 작성 전에 공개용 문의가 지금 답하기 적절한지 판단하고 필요한 부분만 조금 다듬는다. 괜찮은 문의는 그대로 둔다. 기본적으로 오타·띄어쓰기를 고치고 문장을 자연스럽게 정리하되 동물 종류·나이·품종·성별·거주 상황·준비 이력·이동 목적은 유지한다.
- 오래된 문의의 지난 출국일이나 상대 날짜(지난 토요일 등)가 단순 배경 정보라면 미래 날짜나 자연스러운 시점 표현으로 조정할 수 있다. 보호자 출국일과 동물 입국일을 구분하고 원래 이동 계획은 보존한다. 수정한 날짜는 실제 고객 기록이나 확정 일정으로 취급하지 않고 공개용 각색으로 작성 메모에 남긴다. 구체적인 날짜를 고집할 이유가 없으면 불필요하게 만들어 넣지 않는다.
- 단, ‘다음 달에 가능한가’처럼 촉박한 준비기간 자체가 문의의 핵심이면 그 기간을 유지한다. 과거 문의라는 이유로 여유 있는 미래 일정으로 바꿔 질문을 없애지 않는다. 기존 준비 이력에 따른 조건을 밝히고, 처음 준비하면 어려운 절차상 이유와 출국 연기 또는 보호자 선출국 후 가족·지인이 돌보다 동물이 나중에 이동하는 대안을 답변한다. 날짜 조정은 단순히 오래된 달력 날짜를 정리할 때만 적용하며 이 원칙을 우선한다.
- 비용만 묻는 짧은 문의는 답변할 수 있도록 준비 절차·기간·내원 여부 등 원래 맥락에서 자연스러운 질문을 소폭 보탤 수 있다. 새로운 병력·접종·검사 결과나 전혀 다른 상황은 만들지 않는다. 이미 질문이 충분하면 늘리지 않는다.
- 블로그 문의 수정까지 요청받았으면 인용문에도 수정안을 반영하고, 질문 영역과 하단 템플릿 서식은 유지한다. 승인받은 수정안이 있으면 그 문구를 우선한다.
- 제목과 본문은 문의에 나온 내용 중심. 고객이 묻지 않은 비용·절차·기간을 임의로 덧붙이지 않는다. 단, 답을 하는 데 꼭 필요한 전제(예: 대기기간 때문에 일정이 안 되는 경우)는 설명한다.
- 비용 수치는 확인되지 않으면 지어내지 않는다. 금액을 바꾸는 변수를 설명하고 기록을 보고 안내한다는 식으로 정리한다.
- 왕복 여행 문의는 왕복 기준으로 설명한다 (한국 재입국 준비 포함).

## 동물별 주의
- 강아지와 고양이 규정을 섞지 않는다. 문의에 나온 동물 종류의 규정만 쓴다.
- 고양이 문의: 단두종(페르시안·엑조틱·히말라얀 등) 항공 탑승 제한 주의를 대략 두 글에 한 번꼴로 넣는다. 문의 고양이가 단두종이면 반드시 넣는다.
- 2마리 이상 동반: 항공사 1인당 반려동물 예약 제한 주의를 대략 두 글에 한 번꼴로 넣는다.
