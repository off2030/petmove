# 일본 수입

NACCS 메뉴 `Dogs, Cats, Foxes, Raccoons, Skunks` → Import → **Make a new notification**.

## Basic Information

- 신청자 이름 `JINWON LEE AND {OWNER}`; 주소 한국 주소(동·호 포함), 전화 보호자 한국 번호 국제형식, 이메일 lvmcfile@gmail.com.
- 종, Pet(s), 출발 지역 ASIA, 국가 KOREA, REPUBLIC OF.
- 출발일·공항·편명·일본 도착일·공항을 항공편과 대조한다. 터미널은 선택지에 있다는 이유로 추정하지 않는다.
- Carry-on/Checked baggage는 Hand luggage. 상업 항공화물과 구분한다.
- Consignor: 보호자/한국 주소. Consignee: 보호자/일본 체류 주소. 신청자 이름이 공동 표기이므로 동일인 체크를 무조건 사용하지 않는다.
- Remark 3개(각100자 이내), 케이스별 치환:
  1. `I, JINWON LEE, AM SUBMITTING THIS NOTIFICATION ON BEHALF OF THE OWNER, {OWNER}.`
  2. `OWNER CONTACT ON ARRIVAL IN JAPAN: TEL {PHONE}; EMAIL {OWNER EMAIL}.`
  3. Cabin이면 `THE DOG WILL TRAVEL IN THE PASSENGER CABIN AS CARRY-ON BAGGAGE.` 화물실 수하물은 실제 방식에 맞게 표현.

## Animal Information

이름/성별/품종(검색)/생년월일/치수/체중/모색 → 칩 → 접종 → 항체검사 순서. 포메라니안 코드 CP009는 실제 검색 결과에서 확인한 코드다. 다른 품종에 재사용하지 않는다.

- 칩번호·삽입일과 공통 기본값을 입력.
- 접종 최신 먼저. 필요하면 vaccination 2 등을 펼친다.
- 항체결과지 기반 채혈일/결과범주/기관 입력. 한국에서 채혈한 경우 Japan sampling No.
- 5 Other vaccination은 이 업무 관례상 건너뛴다.
- 6 Destination에서 `Please check here if the consignee is identical with the consignee.` 체크(수하인 정보 재사용).
- 7 Remark 건너뜀.
- 같은 보호자의 추가 동물은 Next(Animal), 마지막 동물은 Next(Confirmation).

## Confirmation 및 제출

3번 Attachments에 결과지 **ST : RABIES ANTIBODYTEST**, 이동가방 사진 한 장 **OT : OTHER DOCUMENTS**를 각각 Add로 등록한다. 선택만 하고 등록한 것으로 착각하지 말고 목록의 파일명/분류를 확인한다.

긴 파일명은 거부될 수 있다(관찰된 제한35자). 원본을 보존하고 짧은 영문 복사본 사용: `{PET}_RABIES_TEST.jpg`, `{PET}_CARRIER.jpg`. 설명40자 이내.

신청 전까지만 요청받으면 여기서 멈춘다. 제출 지시가 있으면 **Notification** → 등록번호 확인 → **Apply(検査申請をする)** → Application Completed와 번호 확인. 완료 창 Close는 가능하지만 귀국편 수출 신청에 쓸 메뉴는 유지한다.
