# 일본 출국 / 한국 귀국 수출검역

등록 목록에서 해당 동물의 수입 신고번호 → Procedure Menu → C. **Export inspection**. 기존 신고 재사용 확인창을 승인한다. 또는 메뉴의 새 수출 신청으로 입력할 수 있으나 중복 생성에 주의한다.

## Basic Information

재사용해도 일부 필드는 비거나 출국편이 잘못 복사된다. 전부 대조한다.

- Applicant `JINWON LEE AND {OWNER}`; **Address of applicant는 일본 체류 주소**. 전화 보호자 번호.
- 종/For pet, 목적국 KR(KOREA), 탑재공항 일본 귀국편 출발 공항, AQS office 해당 공항 관할.
- Hand luggage는 carry-on 또는 checked baggage인 경우. 귀국편명과 일본 출국일로 수정한다.
- Consignor 보호자/일본 주소; Consignee 보호자/한국 주소.
- Remark는 **한 문장만**, 수출동물검역 희망일·시간 예약 요청. 나머지 칸 비움. 100자 제한 내 예:
  `I WOULD LIKE TO BOOK AN EXPORT QUARANTINE INSPECTION ON {YYYY-MM-DD} AT {HH:MM}. IS THIS AVAILABLE?`
- 날짜·시간은 저장 기록을 사용한다. 귀국 일정과 모순되면 확인한다. 사용자가 확인한 날짜를 임의 수정하지 않는다. 예약 문의를 기재했다고 예약이 확정된 것은 아니다.
- 첨부가 재사용되지 않을 수 있다. 실제 목록을 확인한다. 수입에서 올린 파일이 수출에도 있다는 주장을 하지 않는다. 필요한 파일이 있으면 확인된 범위에서 첨부한다.

## Export requirements

Re-entering은 **한국 귀국 후 다시 일본에 입국할 계획**에 관한 질문이다. 한국 귀국 자체를 Yes로 해석하지 않는다. 별도 계획이 없으면 No.

Treatments에는 이미 확인된 **마이크로칩, 광견병 접종, 항체검사** 체크. Other vaccination은 해당 증빙/요청이 있을 때. 체크가 화면 갱신으로 풀릴 수 있으므로 세 항목 모두 선택됨을 확인하고 Next.

## Animal Information → Check

이름·성별·품종·생년월일·모색·치수·체중은 재사용값 대조. 처치 상세는 재사용되지 않아 빈칸일 수 있으므로 칩/접종/항체를 수입 자료·결과지와 동일하게 채운다.

- 칩 NECK/OTHER/ISO, 번호·삽입일.
- 접종 최신 먼저, INACTIVATED, 제품/제조사 형식과 유효기간은 공통 기준.
- 항체 채혈일/0.5 이상 범주/결과지 기관 코드. 이름·주소가 조회됐는지 확인.
- 사육/구입 장소, 구입일, 일본 재입국 예정은 자료가 없으면 임의로 만들지 않는다.
- 같은 보호자의 동물이 더 있으면 Next(Animal), 마지막은 **Check**.

Check에서 보호자/목적국/귀국편명·일자/일본 출발공항/처치 선택/동물·칩번호/첨부를 검토한다. 사용자가 지정한 화면까지만 진행한다. 제출 지시가 있으면 **Apply** → Application Completed와 수출 신청번호를 확인한다. 검역소 승인 및 희망 시간 예약 확정은 별도 회신 사항이다.
