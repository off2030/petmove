# 카카오 수신 자료 보관·정보 입력

기본 담당은 [서류 및 기타](../../../docs/work-management/documents.md)다. 검사·일본 신고 담당도 지정 자료를 수신·보관할 때 이 전문 절차를 사용할 수 있다. 보관 후 기관 제출·검사 판정은 해당 담당에 원본 위치와 근거를 연결하며 같은 자료를 동시에 처리하지 않는다.

[실무 운영 기준](../../../docs/work-management/operations.md)의 조직·권한·현재 필드 해석·중단 인계를 적용한다. [다운로드·보관·입력 절차](references/workflow.md)와 접속 전 [Chrome 연결](../petmove-inspection-check/references/chrome-access.md)을 읽는다. Work의 새 결과를 고객에게 안내하는 업무는 [결과 안내 스킬](../petmove-kakao-results/SKILL.md)을 사용한다.

## 범위

- 현재 Work 조직·보호자·동물·칩·여행·첨부를 직접 읽고 실제 카카오 대화의 수신 자료와 대조한다. 비슷한 방 이름·채널명만으로 대상을 정하지 않는다.
- 보관 지시는 지정 수신 파일 업로드까지 포함한다. 확인만 요청하면 업로드하지 않는다. 일반 자료는 보관함에 저장하며 완료 신호를 만드는 다른 첨부란과 구분한다.
- 보관만으로 구조화 값·검사/신고 상태·상담 상태·중요표시를 바꾸거나 메시지를 보내지 않는다. 칩·접종·항체검사 입력을 요청받았을 때만 해당 값·회차를 보존 병합한다.
- 이미 저장된 자료는 재다운로드·중복 첨부하지 않고 원본과 현재 회차를 대조한다. 실제 증빙의 제품·제조사·로트·면역기간·제품 EXP·타 병원 여부와 채혈일·결과·기관을 혼동하지 않는다.

## 복구와 완료

첫 다운로드 오류에 바로 사용자에게 넘기지 않는다. 정상 상담 출처·현재 URL·다운로드 결과·로컬 파일을 확인하고 연결/탭을 정상 복구한다. 차단 우회·쿠키 추출·보안 해제 없이 지원되는 다운로드 API를 사용한다. 같은 실패를 반복하지 말고 해소되지 않는 원인과 최소 사용자 조치를 보고한다.

실제 파일 열림·대상·업로드 완료를 확인하고 저장된 첨부를 재조회해 원본 해시·수량을 대조한다. 구조화 입력은 각 회차 값과 기존 메모·파일·여행·다른 회차 보존까지 재조회한다. 클릭·파일 선택만으로 완료라고 하지 않는다. 부분 성공·중단은 원래 지시와 남은 행동·기한·근거·재개 위치로 공유 이력에 남긴다.
