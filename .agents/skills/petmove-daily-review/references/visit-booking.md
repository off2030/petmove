# 내원 미예약 경고와 카카오 안내

## 대상과 추적

현재 로잔 조직의 Work 서류 탭에서 출국일만 있고 내원일이 없는 여행을 관리한다. 발송 시점·정기 실행일 예외·보고 기준은 [서류 담당 상시 업무](../../../../docs/work-management/operations.md#서류-담당-상시-업무)를 따른다. UI의 `isExportDocBookingRequired`와 정기 점검의 booking 항목을 대조하며, 출국일 경과·날짜 불명확 건을 새 안내 대상으로 만들지 않는다. 서류 준비 완료 여부가 내원 예약 등록을 대신하지 않는다.

`visit-booking-candidates.private.json`을 같은 비공개 공유 이력의 `visitBookingNoticeQueue`에 병합한다. 조직·케이스·여행 토큰·출국일로 대조하고 동일 여행의 문구 확인·실제 발송·회신 이력을 보존한다. 예약 안내를 보냈다고 Work 내원일을 임의로 만들거나 서류 상태를 변경하지 않는다. 실제 예약 등록 또는 취소 근거를 확인한 뒤 연락 할 일을 정리한다.

## 문구 확인과 발송

1. [기존 카카오 방 식별 절차](../../petmove-kakao-results/references/sending.md)로 현재 보호자·동물·여행을 대조한다. 이미 사용자가 요청했거나 같은 출국일의 예약 안내가 발송됐으면 중복 요청하지 않고 회신 대기로 표시한다.
2. 내원가능일·병원 운영 일정과 실제 예약 가능 여부를 확인한다. **목요일·일요일은 휴진이며 예약 안내 시간은 오전 10시~오후 6시**다. Work 내원가능일이 휴진일이면 실제 방문 가능 시작일을 확인해 안내하고 Work 날짜 자체를 임의로 바꾸지 않는다. 출국 2주 전 경고는 예약을 잡으라는 뜻이며 그날 진찰받으라는 뜻이 아니다. 개별 시간대의 예약 확정은 실제 가능 여부를 확인한 뒤 안내한다.
3. 사용자 승인된 기본 문구: `안녕하세요~ [동물]의 [출국일] 출국이 2주 앞으로 다가와 연락드립니다. 출국 전 검진과 서류 발급을 위해 내원 예약을 부탁드립니다. [내원가능일]부터 방문 가능하며, 목요일·일요일은 휴진입니다. 오전 10시부터 오후 6시 사이에 편하신 날짜와 시간을 알려주시면 예약을 도와드리겠습니다~` 내원가능일과 실제 병원 운영 일정을 확인해 넣는다. 정확히 2주 전이 아닌 지연 안내는 첫 문장을 `안녕하세요~ [동물]의 [출국일] 출국 준비를 위해 연락드립니다.`로 바꾼다. 가능일을 확인하지 못했으면 해당 날짜 표현을 빼고 `방문 가능한 일정을 확인해 안내드리겠습니다.`로 쓴다.
4. 위 기본 문구와 출국 2주 전 대상의 정기 발송은 사용자 승인된 상시 지시이며 같은 범위에서 대상별 승인을 반복 요청하지 않는다. 확정된 기존 방에 보내고 같은 방을 재조회해 문구·발송 시각·실패 표시 여부를 확인한다. 불명확하면 재조회부터 하며 반복 전송하지 않는다. 실제 발송 전 공유 이력에 승인 범위와 대상 여행을 기록하고 케이스 잠금·최신 Work/대화 재확인을 수행한다.
5. 같은 공유 큐에 출국일·채팅방 근거·문구 승인·발송 시각·재조회 근거·남은 예약 회신을 기록한다. 일부 실패·방 미확인·승인 대기는 사용자에게 보고하고 중단 지시로 인계한다. 날짜 변경 시 기존 발송을 보존하고 변경된 여행에 필요한 안내를 다시 판단한다.
