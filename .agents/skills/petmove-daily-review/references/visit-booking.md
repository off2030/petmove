# 내원 미예약 경고와 카카오 안내

## 대상과 추적

현재 로잔 조직의 여행별 출국일이 한국 날짜 기준 오늘부터 14일 이내이고 해당 여행의 내원일이 없으면 대상이다. 14일째와 출국 당일을 포함하며 출국일 경과·날짜 불명확 건을 새 안내 대상으로 만들지 않는다. 서류 준비 완료 여부가 내원 예약 등록을 대신하지 않는다. UI의 `isExportDocBookingRequired`와 정기 점검의 booking 항목으로 매일 확인·보고한다.

`visit-booking-candidates.private.json`을 같은 비공개 공유 이력의 `visitBookingNoticeQueue`에 병합한다. 조직·케이스·여행 토큰·출국일로 대조하고 동일 여행의 문구 확인·실제 발송·회신 이력을 보존한다. 예약 안내를 보냈다고 Work 내원일을 임의로 만들거나 서류 상태를 변경하지 않는다. 실제 예약 등록 또는 취소 근거를 확인한 뒤 연락 할 일을 정리한다.

## 문구 확인과 발송

1. [기존 카카오 방 식별 절차](../../petmove-kakao-results/references/sending.md)로 현재 보호자·동물·여행을 대조한다. 이미 사용자가 요청했거나 같은 출국일의 예약 안내가 발송됐으면 중복 요청하지 않고 회신 대기로 표시한다.
2. 내원가능일·병원 운영 일정과 실제 예약 가능 여부를 확인한다. 출국 2주 전 경고는 예약을 잡으라는 뜻이며 그날 진찰받으라는 뜻이 아니다. 시간·입국 요건을 추정해 약속하지 않는다.
3. 사용자에게 대상 방과 실제 보낼 문구를 보여준다. 예: `안녕하세요. [동물]의 [출국일] 출국 준비를 위해 서류 발급 내원 예약을 부탁드립니다. 가능하신 일정을 알려주시면 확인 후 안내드리겠습니다.` 필요할 때 검증한 내원가능일을 명시한다.
4. **문구 확인 후 발송한다.** 문구 작성·채팅방 확인만으로 전송하지 않는다. 승인된 문구를 확정된 기존 방에 보내고 같은 방을 재조회해 문구·발송 시각·실패 표시 여부를 확인한다. 불명확하면 재조회부터 하며 반복 전송하지 않는다.
5. 같은 공유 큐에 출국일·채팅방 근거·문구 승인·발송 시각·재조회 근거·남은 예약 회신을 기록한다. 일부 실패·방 미확인·승인 대기는 사용자에게 보고하고 중단 지시로 인계한다. 날짜 변경 시 기존 발송을 보존하고 변경된 여행에 필요한 안내를 다시 판단한다.
