# 검사결과 고객 안내

[검사 담당](../../../docs/work-management/inspection.md)의 결과 안내 절차다. 일반 서류 보관·일본 검역소 회신과 구분하며, 원본의 보관 위치는 서류 담당과 공유해 중복 발송을 막는다.

[실무 운영 기준](../../../docs/work-management/operations.md), [공유 이력](../../../docs/laptop-daily-check-handoff.md)을 적용한다. 수신 파일 보관/정보 입력은 [자료 스킬](../petmove-kakao-documents/SKILL.md), 기관 신청 대조는 [검사 스킬](../petmove-inspection-check/SKILL.md)이다.

## 권한과 대상

검사 담당의 상시 발송 지시는 [실무 운영 기준의 권한](../../../docs/work-management/operations.md#권한)을 따른다. Work에 입력된 현재 회차 결과지와 기존 고객 방을 확정하고 결과 사실에 맞는 안내문·원본 결과지를 발송·재확인한다. 매번 문구 확인·별도 발송 승인을 다시 요구하지 않는다. 단순 검토·초안만 요청한 개별 작업은 그 좁은 범위를 따른다. 카카오 UI는 파일 선택만으로 즉시 전송할 수 있다.

로잔 조직의 현재 케이스·여행·검사 회차를 직접 조회한다. 카카오 채널 이름을 DB 조직으로 오해하지 않는다. **원본 확인 → 카톡 발송 → 실제 발송 재조회 → 해당 Work 검사 회차 완료 → 저장 재조회** 순서를 지킨다. 발송 전 완료 처리하지 않으며 기존 완료를 되돌리지 않는다. 상담 상태·중요표시·신고 상태는 이 작업으로 바꾸지 않는다.

## 연락 할 일과 결과 확인

1. 정기 실행은 [정기 점검 스킬](../petmove-daily-review/SKILL.md)로 시작한다. 실시간 등록 이벤트를 감지하는 기능으로 표현하지 않는다.
2. `node scripts/inspection-result-notice-snapshot.mjs work/naver-inquiries/result-notice-current.private.json`의 전체 첨부 지문을 공유 `kakaoResultNoticeQueue.prospectiveOnly`의 적용 시각·기존 첨부 지문과 비교해 적용 이후 새로 입력된 결과지만 선별한다. 전체 조회는 신규 식별용이며 과거 원본·카톡 발송 이력을 다시 조사하는 지시가 아니다. 기존 자료는 발송 완료로 추정하지도, 과거 큐를 다시 실행하지도 않는다. 신규 입력 대상은 검사 done만으로 제외하지 않는다.
3. documents/notes의 같은 파일은 경로로 중복 제거하고 재등록/교체 파일은 식별정보·크기·시각으로 구분한다. 제목·태그·resultCandidate는 단서다. false인 새 파일도 원본과 문맥을 확인한다. 원본 미확인은 확인 할 일로 남기며 단순 seen으로 넘기지 않는다.
4. 원본 보호자·동물/칩·채혈일·검사 종류·기관·결과를 현재 회차와 대조한다. 업로드일·발급일·채혈일을 구분한다. 실제 수치/비교부호를 보존하며 결과 상태와 공식 검사 상태를 혼동하지 않는다.
5. 큐에는 조직·케이스/회차·첨부 식별정보·등록/확인일·남은 행동·기존 채팅방 근거·문구 확인·기보고 시각을 남긴다. 검사/신고의 독립 상태를 만들지 않는다. 과거 제외 큐와 사용자 직접 확인 기록은 보존하되 자동 검색·발송·상태 보정·반복 요청하지 않는다.
6. 신규 입력 결과와 적용 이후 생긴 발송 실패·일부 성공만 처리한다. 처리 결과와 대상 신규 건의 미확인·불일치·실패·중단은 동물·보호자·검사·남은 행동과 함께 보고한다. 발송 완료 건은 다음 점검에서 제외한다. 정상 감독 항목은 내부 기록으로 두며 과거 제외 큐를 매일 알림으로 되살리지 않는다.

## 결과 발송과 Work 완료

[원본 대조·채팅방·발송 절차](references/sending.md)와 [Chrome 연결](../petmove-inspection-check/references/chrome-access.md)을 읽는다. 실제 대화·동물·검사/여행으로 기존 방을 확정하고, 발송 직전 최신 대화와 공유 이력에서 사용자 수동 발송까지 중복 확인한다.

실제 재조회한 문구·이미지 수량·발송시각 또는 사용자의 완료 확인으로만 발송 완료를 판정한다. 일부 성공은 남은 첨부만 이어 보내고 불명확하면 실제 대화부터 재조회한다. 발송이 확인된 뒤 같은 케이스 잠금 안에서 최신 Work를 읽고 해당 회차만 완료·저장 재조회한다. 결과 화면 보관 후 공유 최신본 병합·동일 파일 갱신·원본 재조회를 마친다. 이미 발송된 건은 재발송하지 않고 필요한 Work 완료 반영만 진행한다. 충돌·실패는 남은 단계와 함께 보고한다.
