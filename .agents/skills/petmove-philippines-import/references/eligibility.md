# 신청 전 요건과 시기

신청할 때마다 [BAI 현행 안내](https://www.bai.gov.ph/Stakeholders/PetImport), [변경 안내](https://www.bai.gov.ph/Stakeholders/NewPetImport), 연결된 원문 고시·서식과 실제 포털 공지를 읽는다. 마지막 작성 확인일은 2026-11-06이다. 저장된 요약이나 이전 동물의 승인 사례를 현재 규정으로 대체하지 않는다.

## 완비 판정

아래 항목별로 확인값·원본 위치·대조 결과·확인 시각을 비공개 실행 폴더에 남긴다. `미확인`은 통과가 아니다. 적용 규정이 충돌하면 해당 건 자동 제출을 보류하고 구체적인 충돌과 필요한 기관 확인을 보고한다.

| 확인 항목 | 통과 근거 |
| --- | --- |
| 동일 대상·여행 | 로잔 조직, caseId, 정확한 필리핀 여행 토큰, 보호자 영문명/여권, 동물·칩·출발/도착일·동반자 일치. 왕복·2차 여행을 섞지 않음 |
| 실제 신청 필요·중복 | Work 수입 슬롯, 기존 초안·신청·발급 허가와 비공개 이력 대조. 타 계정·타 동물 신청을 변경하지 않음 |
| 사람 정보 | 실제 수입자·동반자의 연락처·주소·필리핀 체류지·여권 등 현재 필수값 확보. 이름만으로 국적·성별을 추정하거나 전화번호를 만들어 넣지 않음 |
| 동물 정보 | 종·품종·생일/월령·성별·체중·칩, 나이·건강/임신·출산 제한과 수입 수량 요건 충족. 필요한 건강 사실은 확인된 원본/사용자 확인으로만 판단 |
| 임상 기록 | 칩 증빙, 유효한 광견병·종합백신·구충 기록의 실제 날짜·제품·유효기간·서명/발급 확인. 달력에 없는 날짜, Work/원본 불일치, 판독 불가를 통과시키지 않음 |
| 첨부 | 현재 규정의 필수 서식/서명·칩/접종/구충 증빙·실제 동물 사진 확보. 파일을 실제로 열어 전 페이지와 동일 대상을 확인. 수신/목록 존재만으로 완비 아님 |
| 신청 시기 | 여행일 확정, 신청 기준 접종·구충 경과일, 심사 처리기간·업무일, 허가 유효기간과 운송/입국일을 대조. 날짜 구간과 다음 적정 신청일을 명시 |
| 권한·포털 | 올바른 계정/Importer, 잠금·중단 지시·확약 확인, 비용 확인. 현재 사용자 승인 범위와 도구 정책 내에서만 제출 |

## 규정 전환을 놓치지 않기

2026 안내의 접종·구충 경과일, 백신 유효기간, 처리기간을 매번 현행 원문과 확인한다. 과거 화면의 부스터 예외 등을 현재 BAI 안내보다 우선하지 않는다. 3년 백신은 실제 제품/증빙과 현행 인정 범위를 대조한다.

2027-01-01부터 RNATT·Form 1 요건이 바뀐다. **신청일과 승인일을 모두 확인**한다. 변경 안내는 2026-12-31까지 승인된 허가의 유효기간 내 이용 예외도 설명하므로 출국 연도만으로 일괄 판정하지 않는다. 연말 제출·연초 승인처럼 적용이 불명확한 건은 예외를 추정하지 않고 확인한다. 새 Form 1의 각 항목·수의사/정부 확인, RNATT 채혈·기관·결과·경과일, 내·외부 구충의 새 기준을 원문대로 대조한다. Form 1과 출국 정부 검역증명서(IVHC)는 별개다.

2027 안내의 허가 유효기간은 발급 후 60일, 1회 운송용이다. 현재 신청에도 적용되는지 현행 규정/포털로 확인하고 실제 발급된 허가의 날짜를 최종 기준으로 대조한다. 처리 예상기간은 보장일이 아니다. 도착일이 유효기간 밖이 되거나 심사 여유가 부족한데 적합으로 표시하지 않는다. 일정을 앞당기거나 늦추는 결정은 임의로 하지 않는다.

허가 신청 시점에 필요한 기록과 출국 직전에 발급할 정부 검역증명서를 구분한다. 아직 발급 시기가 아닌 출국 서류 때문에 적법한 사전 신청을 불필요하게 막지 않되, 원문에서 신청 필수로 정한 서류는 생략하지 않는다.

## 비용

InterCommerce는 최종 접수 때 계정 잔액을 자동 차감할 수 있다. 최종 단계 전에 현재 표시/안내된 금액·지급처·목적과 유효한 비용 승인을 확인한다. 이전 한 건의 차감액을 모든 건의 고정 수수료나 포괄 결제 승인으로 간주하지 않는다. 충전·카드 결제·추가 비용이 필요하고 승인 범위가 없으면 작성본과 정확한 금액을 준비해 보고한다. 비용을 확인할 수 없으면 재제출로 추측하지 않는다.
