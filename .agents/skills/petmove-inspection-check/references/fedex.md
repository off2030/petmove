# FedEx 검사 검체 발송

사용자가 페덱스 발송 신청을 지시했을 때 적용한다. 대상·권한·잠금·중단 인계는 [실무 운영 기준](../../../../docs/work-management/operations.md)을 따른다. 이 절차를 저장했다는 이유로 새 발송이나 픽업을 자동 실행하지 않는다.

## Work 확인과 템플릿 선택

1. Work 현재 저장값을 직접 조회해 조직·대상 동물·검사기관·회차·실제 발송 검체 수를 확정한다. 동물이 한 마리여도 검체 수를 한 개로 추정하지 않는다. 특정 이름 없이 검사 예정 대상을 가리키는 지시도 현재 검사탭 기준으로 조회하며 후보가 여러 개면 구분한다.
2. [Chrome 연결](chrome-access.md)에 따라 펫무브 프로필에서 FedEx에 접속하고 기존 발송물·예약을 확인한다.
3. 검사기관에 맞는 기존 발송물 템플릿을 선택하고 수취처를 대조한다. 기본 선택값을 무조건 사용하지 않는다.

| Work 검사기관 | FedEx 템플릿·수취처 |
| --- | --- |
| KSVDL-R (`ksvdl_r`) | **KS Rabies Lab** — Kansas State Rabies Laboratory / Dr. Dale Claassen |
| 일반 KSVDL | **KSVDL** — Kansas State Vet Diagn Lab (KSVDL) / Diagnostic Receiving |
| ARC-OVI | **ARC-OVI** — Onderstepoort Veterinary Research |
| VBDDL | **VBDDL** — Vector Borne Disease Diagnostic Lab |

템플릿 이름은 선택 단서이며 현재 수취처·Work 기관 설정을 다시 대조한다. 특히 KSVDL-R과 일반 KSVDL을 서로 바꾸어 쓰지 않는다.

## 발송 양식과 첨부

- **KS Rabies Lab의 저장 기본값은 샘플 1개, 포장 총중량 0.30kg, 추가 문서 첨부 없음**이다. 1개 기준 검체 순중량은 0.01kg, 세관 신고금액은 US$1로 계산된다. 실제 발송 수량이 다르면 이번 발송 양식에서 조정하며 공용 템플릿을 임의로 덮어쓰지 않는다. 다른 기관의 검체 구성까지 1개로 일괄 변경하지 않는다.
- 매번 **펫무브워크의 인보이스·배송 서류 출력 기능**으로 해당 기관·실제 검체 수·발송일에 맞는 인보이스와 관련 서류를 새로 출력·다운로드한다. 이전 다운로드 파일이나 템플릿에 남은 첨부를 그대로 재사용하지 않는다. 작업 파일은 Git 제외 비공개 폴더에 둔다.
- 출력 PDF의 모든 페이지를 확인해 기관·수취처·검체 종류와 수량·발송일·금액·서명 등 실제 값을 FedEx 양식과 대조한다. PDF가 합본이면 인보이스와 관련 서류가 모두 포함됐는지 확인한다. KSVDL-R의 Work 출력에는 인보이스, 검체 면제 선언서(ESD), 세관 관련 문서가 포함되므로 현재 출력 구성을 확인한다.
- Work에서 인보이스와 관련 서류가 **합본 PDF로 출력되면 동일한 합본 파일 전체를 Commercial Invoice와 추가 문서 두 항목에 각각 업로드**한다. 페이지를 분리하지 않는다. 업로드 후 두 항목 각각의 파일명과 실제 미리보기/첨부 목록으로 확인한다. 빈 기본 템플릿을 서류 첨부 불필요로 해석하지 않는다.
- 총 포장 중량은 검체 순중량과 구분한다. 포장 중량·서비스·발송일·픽업 정보는 실제 발송 조건과 출력 서류를 대조한다. 서로 다르면 근거 없이 같은 값으로 맞추지 않는다.
- 서비스는 별도 지시가 없으면 현재 제시된 요금 중 가장 저렴한 것을 선택한다. 템플릿에 저장된 서비스를 그대로 확정하지 말고 실제 요금·배송 예정일을 확인한다. 픽업은 사용자가 지정한 날짜·시간대로 예약하고 발송일·출력 서류와 맞는지 대조한다.

## 제출과 확인

페덱스 신청 지시에는 [공통 권한](../../../../docs/work-management/operations.md#권한)에 따라 발송 신청·픽업 예약·라벨 PDF의 Work 저장까지 진행한다. 실제 제출 전 케이스 잠금 아래 최신 Work·FedEx 기존 발송물·예약을 다시 확인하고 중복을 막는다. 화면 확인·템플릿 수정 요청은 발송 제출 지시가 아니다.

발송은 실제 운송장 번호·라벨·확정 내역으로, 픽업은 실제 예약번호·날짜·시간대로 확인한다. 발송 완료를 픽업 예약 완료나 검사 진행으로 대신 표시하지 않는다. 실패·불명확한 제출은 중복 실행 전에 기존 발송물/예약부터 재조회하고 재개 위치를 남긴다.

신청 완료 후 발급된 라벨 원본 PDF를 다운로드해 해당 Work 케이스의 보관함에 저장·재조회하고, 저장된 파일의 페이지·운송장 번호·해시를 대조한다. 검사결과나 수입허가증 첨부란에 넣지 않고 검사 상태도 바꾸지 않는다.

**종이 인쇄와 서명은 사용자 담당**이다. 에이전트는 종이 인쇄를 시도하거나 서명을 추가하지 않는다. 발송·픽업 확정과 라벨 PDF의 Work 저장 검증이 끝나면 맡은 업무는 완료이며, 사용자 인쇄·서명을 에이전트 오류·미완료·재개 대상으로 남기거나 매일 재확인하지 않는다. 보고에는 실제 운송장·픽업 예약번호와 날짜·시간, 요금, 라벨 저장 결과를 적는다.
