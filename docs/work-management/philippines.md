# 필리핀 수입허가증

담당 4는 [필리핀 SPSIC 스킬](../../.agents/skills/petmove-philippines-import/SKILL.md)로 반려견·반려묘 수입허가 신청과 승인 확인을 맡는다. 상시 권한·완료 기준은 [공통 실무 기준](operations.md#필리핀-담당-상시-업무) 한 곳에 유지한다.

업무 PC에서 매일 10:30 한국 시간에 `--scope philippines`로 전체 신고 대상과 신청 건을 점검한다. 목·일도 포함한다. 기존 검사·일본·서류 예약의 실행 요일과 노트북 중지는 유지한다. 다른 국가의 수입·수출은 이 정기 범위에 포함하지 않는다.

현재 Work DB·원본 첨부·기관 기존 신청을 대조해 정보·서류·신고 시기가 모두 맞는 건만 진행한다. 접수와 승인을 구분하고 신청된 미종결 건은 매일 승인 여부를 보고한다. 승인서 저장·Work 반영 실패, 보완·반려·규정 변경·사용자 조치 필요도 보고한다.

일반 자료 수신·보관·임상 정보 입력·정부 출국서류 준비·내원 안내는 [서류 담당](documents.md)의 범위다. 필리핀 허가 신청에 필요한 원본을 이어받으며 중복 제출·상태 복제를 만들지 않는다. 기존 공유 이력의 필리핀 허가 관련 미완료는 대상·여행을 대조하고 `workArea: philippines`로 담당만 정리한다. 다른 담당의 임상 자료 불일치·일반 서류 작업은 원래 담당을 유지한다.
