# 앱·웹·홈페이지 개발/관리

보호자용 펫무브 앱·웹, 펫무브워크 제품 기능, 펫무브 홈페이지 제작·관리 업무를 맡는다. 홈페이지의 구성·디자인·페이지 제작·검색 노출 관련 구현·기능·배포·운영 수정도 이 영역이다. 실제 글의 기획·작성은 콘텐츠 지침을 함께 적용한다.

1. 변경할 제품과 사용자의 문제·기대 동작을 확인한다. 홈페이지와 보호자 앱이 같은 도메인을 쓰더라도 수정할 기능과 코드를 구분한다.
2. 실제 코드 위치를 확인하고 저장소 및 해당 앱의 로컬 지침을 읽는다. `apps/admin`은 펫무브워크, `apps/portal`은 보호자 앱의 기존 진입점이다. 홈페이지의 구현 위치는 작업 시 코드에서 확인하며 경로나 배포 프로젝트를 추정하지 않는다.
3. 기존 작업 트리와 관련 없는 변경을 보존한다. 필요한 검증을 실행하고 결과를 기록한다. 기능 개발을 이유로 실제 고객 케이스를 테스트용으로 변경하지 않는다.
4. 코드 수정·미리보기 확인·운영 반영을 구분해 보고한다. 배포 요청의 권한과 해당 저장소 절차를 따른다.

보고에는 무엇이 달라졌는지, 어떤 검증을 했는지, 실제 반영 위치와 남은 문제를 담는다. 코드 작업의 완료와 실제 고객 검사·신고의 완료를 혼동하지 않는다.
