# 네이버 블로그 국가별 가이드 작성 방법

> 네이버 블로그에 올릴 "강아지 OO 여행, 검역 절차 총정리" 시리즈의 작성 지침.
> 초안을 요청받으면 이 문서를 먼저 읽고 규칙대로 작성한다.

## 작성 지침

펫무브 웹사이트의 국가별 가이드 글을 네이버블로그에 포스팅하기 위한 글 변환 작업 프로젝트

1. www.petmove.co.kr -> 가이드 -> 여행지별 가이드 글이 작업 대상
2.  컨텍스트에 있는 네이버블로그 시리즈 글이 템플릿
3. 여행지 명을 말해주면, 해당 여행지 글을 1번 사이트에서 찾아서 2번 테플릿 형태로 변환
4. 네이버에 바로 붙여넣을 수 있는 형식으로 만들 것
5. 제목 다음에 이 글에 붙여넣을 태그 작성



## 종(種) 범위 규칙

제목이 "강아지 OO 여행"이면 **본문과 태그 전체가 강아지 전용**이다.
고양이는 한 번도 언급하지 않는다. 고양이 정보는 별도 글로 쓴다.

www 원본 가이드는 "강아지·고양이 OO 입국 준비"로 두 종을 함께 다룬다.
변환할 때 고양이 문장이 그대로 딸려오기 쉬우므로 아래 자리를 반드시 확인한다.

| 자주 남는 자리 | 원본 표현 | 강아지 글에서 |
|---|---|---|
| 마이크로칩 | 동물등록(강아지 필수, 고양이 선택) | 동물등록 신청 필수 |
| 최소 연령 | 고양이는 연령 제한 없음 | 삭제 |
| 종합백신 | 고양이(FVRCP)·범백혈구감소증 | 삭제, 강아지 백신만 |
| 서류 대상 | 고양이는 해당 없음 | 삭제 |
| 도착 검역 | 고양이는 서류 없이 건강 확인 | 삭제 |
| 단두종 예시 | 퍼그, 불독, 페르시안 | 퍼그, 불독, 시츄 |
| 구충·촌충 | 고양이와 페럿은 요건 없음 | 삭제 |

강아지에만 적용되는 요건도 "**강아지만 해당**"처럼 고양이와 대비해서 쓰지 않는다.
그냥 요건을 서술한다. 강아지 글에서는 강아지가 기본값이다.

## 제목 작성 규칙

형식이 고정돼 있다. 아래 한 줄을 그대로 쓰고 나라 이름만 바꾼다.

```
[2026] 강아지 필리핀 여행, 검역 절차 총정리 | 수의사
```

| 자리 | 내용 | 비고 |
|---|---|---|
| `[2026]` | 발행 연도 | 해가 바뀌면 갱신 |
| `강아지 OO 여행` | 종 + 나라 | 종 범위 규칙과 일치시킬 것 |
| `검역 절차 총정리` | 시리즈명 | 고정 |
| `\| 수의사` | 꼬리말 | 고정 |

⚠️ 본문 안 소제목 `강아지 OO 여행, N단계 핵심 절차`는 제목이 아니다.
제목 자리에 이 형태를 쓰지 말 것.

## 태그 작성 규칙

제목 바로 다음에 넣는다. **`#` 접두 + 공백 구분, 한 줄**로 쓴다.
쉼표 구분이나 목록 형태로 쓰지 말 것. 태그 안에는 띄어쓰기를 넣지 않는다.

예시(미국):

```
#강아지미국여행 #강아지미국검역 #강아지미국데려가기 #강아지미국입국준비 #강아지해외출국준비 #CDC수입신고 #강아지생후6개월 #광견병항체검사 #반려동물미국출국 #강아지미국비행기 #펫무브 #로잔동물의료센터
```

12개 고정 슬롯으로 구성한다. 나라가 바뀌어도 6~8번만 새로 정하면 된다.

| 슬롯 | 내용 | 비고 |
|---|---|---|
| 1~4 | 나라 이름만 교체 | 여행·검역·데려가기·입국준비 |
| 5 | 강아지해외출국준비 | 고정 |
| 6~8 | 그 나라 고유 절차 | 미국=CDC·6개월, 영국=화물·촌충 |
| 9~10 | 공통 | 반려동물OO출국, 강아지OO비행기 |
| 11~12 | 브랜드 | 펫무브, 로잔동물의료센터 |

⚠️ 고양이 태그를 넣지 않는다. 아래 종 범위 규칙 참고.

네이버 태그는 최대 30개까지 넣을 수 있다. 특정 글에서 노출을 더 넓히고 싶으면
6~8번 자리를 늘려서 확장하되, 기본은 12개로 유지한다.

## 표 작성 규칙

표는 마크다운 표 문법으로 작성한다. 채팅에서 HTML 표로 렌더링되므로,
사용자가 렌더링된 표를 복사해 네이버 블로그에 "서식 유지"로 붙여넣으면
스마트에디터 표로 그대로 변환된다. 코드블록에 넣지 말 것.

제약:

- 열은 3개 이하 (모바일에서 4열 이상은 글자가 뭉갬)
- 셀 병합 금지 — 붙여넣기 때 구조가 깨짐
- 빈 셀 금지. 헤더 포함 모든 칸을 채운다
- 셀 안에는 한 줄 텍스트만. 불릿·링크·줄바꿈은 붙여넣기 때 손실됨
- 셀 텍스트는 15자 이내로 짧게

사용 판단:

- 항목 3개 이상 × 속성 2개 이상을 비교할 때만 표를 쓴다
- 단순 나열이나 순서 설명은 불릿으로 (표로 만들면 오히려 읽기 나쁨)
- 색상·아이콘이 필요한 디자인 표는 이미지로 만들고, 아래에 텍스트 요약을 병기

## 규정 확인 절차

초안의 날짜·일령·유효기간은 반드시 코드의 규정 정의와 대조한다.
truth는 `procedure-checks` (앱 판정 로직)이며, www 가이드와 불일치하면
어느 쪽이 맞는지 확인한 뒤 초안에 반영하고 사용자에게 보고한다.

## 제출 전 체크리스트

초안을 내놓기 전에 아래를 전부 확인한다. 하나라도 걸리면 고치고 다시 확인한다.

- [ ] 제목이 `[연도] 강아지 OO 여행, 검역 절차 총정리 | 수의사` 형식이다
- [ ] **고양이 언급 0건** — `고양이`, `페르시안`, `FVRCP`, `범백`으로 훑어본다
- [ ] 제목·본문·태그의 동물 종이 서로 일치한다
- [ ] 태그 12개, `#` 접두 + 공백 구분 한 줄, 제목 바로 다음 위치
- [ ] 표는 3열 이하, 빈 셀 없음, 헤더 채움
- [ ] 날짜·일령·유효기간을 `procedure-checks`와 대조했다
- [ ] 원본의 접힘(`details`) 영역에서 핵심만 뽑고 나머지는 뺐다
- [ ] 원본에 있던 영상·이미지는 별도 안내로 표시했다 (붙여넣기로 안 들어감)
- [ ] 빈 줄을 개수로 옮기지 않고 문단/줄바꿈/빈 줄로 구분해서 썼다

## 미결 사항

- [ ] 마무리에 "이어질 포스팅" 예고를 넣을지 (태국·필리핀 공통)
- [ ] 마이크로칩 단락에만 리드인 문장이 없는 것을 통일할지
- [ ] 글 하나당 표 개수 상한 (1~2개 제안)
- [ ] 표 위치 고정 여부 (큰 흐름 설명 직후, 단계별 상세 앞)

큰 흐름을 이해하셨다면, 이제 각 단계별 핵심 포인트를 확인해보세요.

1. 마이크로칩 이식

강아지 싱가포르 입국 준비의 출발점은 마이크로칩 이식입니다. 마이크로칩 이식 전에 한 접종·검사 기록은 인정되지 않습니다.

✔ 핵심 포인트
타이밍: 가장 먼저 실시
내장형만 인정 (외장형 X)
ISO 11784 또는 ISO 11785 Annex A 표준 마이크로칩 사용 (15자리 번호)
강아지는 동물등록 필수 (고양이는 선택)
⚠️ 이식 후 매 준비 단계마다 스캔이 잘 되는지 반드시 확인 (스캔 안 되는 사례 존재)
⚠️ ISO 표준이 아닌 칩이 있는 경우 보호자가 리더기를 직접 지참해야 하므로, ISO 표준 칩으로 새로 이식 권장

2. 광견병 예방접종

✔ 핵심 포인트
타이밍: 마이크로칩 이식 후 & 생후 12주(84일) 이후
불활화(사독) 백신 또는 재조합(변형) 백신 사용
접종 횟수는 백신 제조사 권장사항 기준 (유효한 기초 접종 및/또는 최신 부스터 접종)
⚠️ 접종 기록에 마이크로칩 번호, 접종일, 백신명, 로트번호, 수의사 서명 반드시 기재
⚠️ 싱가포르 입국 시점까지 면역 유효기간이 남아있어야 함

3. 종합백신 접종

싱가포르는 광견병뿐만 아니라 주요 감염병에 대한 예방접종도 필수로 요구합니다.
✔ 핵심 포인트
타이밍: 백신 제조사 권장에 따라 접종, 출국 최소 14일 전까지 완료
강아지(DHP): 디스템퍼(홍역), 아데노바이러스 1형(간염), 파보바이러스 2형
고양이(FVRCP): 범백혈구감소증(FPV), 고양이 허피스바이러스 1형(FHV-1), 고양이 칼리시바이러스(FCV)
⚠️ 접종 기록에 마이크로칩 번호, 접종일, 백신명, 로트번호, 수의사 서명 반드시 기재

4. 광견병 항체검사

싱가포르 준비에서 가장 어려운 단계입니다. 검사기관 선택에 주의하세요.

✔ 핵심 포인트
타이밍: 광견병 예방접종 후 최소 28일 경과 후 채혈
검사기관: WOAH 레퍼런스 랩 또는 Schedule I·II 국가의 관할 당국이 승인한 검사기관
검사법: WOAH 지정 검사법(FAVN 또는 RFFIT)만 인정
합격 기준: 0.5 IU/ml 이상
검사 유효기간: 1년 (채혈일 기준)
⚠️ 시료는 UN3373(Category B) 운송 규정에 따라 패키징·라벨링, 국제특급우편(EMS)은 배송 금지 — DHL 등 특송 이용
⚠️ 검사 신청은 임상수의사만 가능 (개인 신청 불가)
⚠️ 결과까지 약 1개월, 불합격 시 부스터 접종 후 재검사로 1~2개월 이상 추가 소요
검사의뢰 [펫무브 카카오톡 문의하기] [전화 02-872-7588]

5. 대기기간(90일)

✔ 핵심 포인트
광견병 항체검사 채혈일 기준, 출국일까지 최소 90일 경과 필요 (예: 1월 1일 채혈 → 4월 1일 이후 출국)
채혈일 기준 12개월(1년) 이내에 출국해야 함
⚠️ 90일이 지나지 않은 상태에서 출국하면 입국 거부 또는 더 긴 계류가 적용될 수 있음

6. 항공권 구매

✔ 핵심 포인트
타이밍: 채혈일 기준 90일 이상 지난 날짜로 출국일 확정
계류 시설 예약·수입 라이선스 신청·동물검역 예약에 도착 일정이 필요하므로 항공권을 먼저 확정
항공권 구매 후 반려동물 운송 예약 필수

7. 계류 시설 예약

✔ 핵심 포인트
