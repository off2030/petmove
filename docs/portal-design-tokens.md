# 펫무브 디자인 스케일

화면마다 매직 넘버(`borderRadius: 18`, `fontSize: 13` …)를 박지 말고, 아래 단일 출처에서 가져온다.

- **색** → `apps/portal/lib/palette.ts` 의 `C` (globals.css `--pm-*` 토큰 참조)
- **둥글기·글꼴·간격** → `apps/portal/lib/tokens.ts` 의 `RADIUS` / `TEXT` / `SPACE`

값은 기존 화면들이 사실상 따르던 스케일을 명문화한 것이라, 새 화면은 이 값만 쓰면 자동으로 일관된다.

## 둥글기 — `RADIUS`

| 토큰 | 값 | 용도 |
|---|---|---|
| `pill` | 999 | 칩 · 아바타 · 하단 nav 탭 (원형) |
| `sheet` | 22 | 바텀시트 · 플로팅 바 |
| `card` | 18 | 바깥 카드 — 편집/step 카드, 서류 상세 |
| `inner` | 16 | 안쪽 입력 카드 — 여정 입력 그룹, 정보 행 |
| `button` | 14 | 버튼 (저장 등) |
| `field` | 10 | 입력칸 · 작은 박스 |
| `chip` | 6 | 점 · 배지 · 체크박스 |

> 핵심 규칙: **바깥 카드 18 / 안쪽 입력 카드 16** (2단 중첩).

## 글꼴 — `TEXT` (px)

| 토큰 | 값 | 용도 |
|---|---|---|
| `cap` | 11 | mono-cap 라벨 (대문자 트래킹) |
| `meta` | 12 | 메타 · 보조 텍스트 |
| `body` | 13 | 본문 · 필드 라벨 |
| `button` | 14 | 버튼 라벨 |
| `input` | 15 | 입력값 |

> 제목(serif)은 헤딩 단계라 인라인 유지: **h1 28 · 이름 20 · hero 18**.

## 간격 — `SPACE` (px)

| 토큰 | 값 | 용도 |
|---|---|---|
| `page` | 24 | 페이지 좌우 패딩 |
| `card` | 18 | 바깥 카드 패딩 |

> 여정 입력 카드는 `'4px 16px'` (저밀도 — 라벨/입력이 촘촘).
