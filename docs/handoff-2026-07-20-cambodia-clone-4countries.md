## 4. 3개국 각각 — 지금 아는 것과 확인할 것

세 나라 모두 **베트남에서 복제된 값**을 그대로 갖고 있다. 아래 "복제값"은 근거 없이 들어온
것이므로 조사 결과로 정정하거나 제거해야 한다.

### 몽골 (mn) — `procedure-checks/mn.ts`
- 확정 델타(사용자 제공): 칩 **필수 O** / 광견병 **달력 3개월** / 접종 후 **30일** 대기
- 복제값(검토 대상): 3년 백신 불인정 blocker, 도착 미충족 시 격리 문구, "마이크로칩과 서류를 확인해요"
- **유리한 점**: 캄보디아와 달리 **한국 APQA 수출국가별 검역조건 목록에 몽골이 있다.**
  USDA APHIS Mongolia 페이지도 존재. 캄보디아보다 훨씬 나은 출처를 기대할 수 있다.
- 확인 필요: 맡기기 **기간 비어 있음** (www 가이드에 문장 있는지)
- 구버전 주석이 남긴 단서: "개에 한해 에키노코쿠스 구충 권장(몽골 풍토병)" — 카드로 만들지 판단

### 우즈베키스탄 (uz) — `procedure-checks/uz.ts`
- 확정 델타: 칩 **필수 O** / 광견병 **달력 3개월** / **30일** 대기
- 복제값: 3년 백신 blocker, 격리 문구
- ⚠️ **최대 미결 — 항체검사가 입국 필수인가, 귀국용인가.**
  구버전 프로파일 주석은 "입국용 항체검사(유효기간 1년) 필수 → 편도에서도 표시"였는데,
  베트남 복제하며 `titer.need: 'return-only'`(귀국용, 왕복에만 표시)로 **뒤집었다.**
  근거 미확인 상태다. 입국 필수가 맞으면 편도 케이스에 항체 카드가 안 떠서 **입국을 못 하는
  사고**가 난다. 우즈베키스탄 작업의 1순위.
- 맡기기 기간은 이미 '최소 1~2개월' 들어 있음

### 캐나다 (ca) — `procedure-checks/ca.ts`
- 확정 델타: 칩 **필수 X** / 광견병 **달력 3개월** / 접종 후 대기 **0일**(대기 룰 자체 없음)
- **캄보디아와 정반대로 공식 자료가 충실한 나라.** CFIA(Canadian Food Inspection Agency)
  Import Reference Document + CBSA 안내가 공개돼 있다. 조사 정확도가 가장 높을 것.
- ⚠️ **3년 백신 blocker 제거 1순위.** CFIA 는 다년 백신을 인정할 가능성이 매우 높다.
  근거 없이 캐나다 여행자에게 재접종을 강요하는 상태다.
- ⚠️ 도착 카드 문구 전면 재검토 필요. 캐나다는 '동물검역소 검역'이 아니라 **CBSA 국경 검사**
  모델이라 "공항 동물검역소에서 검역" 자체가 안 맞을 수 있다. 격리 문구도 근거 없음.
- 확인 필요: 맡기기 **기간 비어 있음**
- 구버전 주석 단서: "상업용 8개월 미만 강아지(고위험국) 금지 — 동적 확인 필요"

(무엇을 하는가·격리 기간·발급 서류 이름) ⑧동반 마리수·금지 견종 ⑨지정 입국 공항

## 6. 사용자가 결정할 항목 (3개국 공통 — 조사 후 물어볼 것)

캄보디아에서 실제로 물었던 것과 같은 구조다. 조사 결과를 붙여 표로 정리해 보고할 것.

1. **3년 백신 blocker를 어떻게 할 것인가** — 나라별로 (가)완전 제거 / (나)blocker→warning 강등
   / (다)유지. 캄보디아는 **(가)** 를 택했다. 캐나다는 (가)가 유력.
2. **도착 검역 카드 문구** — 격리 일수·격리 여부·발급 서류 이름. 근거 없으면 격리 주장 삭제.
3. **우즈베키스탄 항체검사** — 입국 필수(편도에도 표시) vs 귀국용(왕복만). ← 단독 최우선
4. **맡기기 기간(몽골·캐나다)** — www 가이드에 문장 없으면 비워 둘지(추정 금지가 원칙)
5. **불확실성 안내 문구를 카드에 넣을지** — 캄보디아는 "넣지 않음"으로 결정
6. **현지 수출검역 카드를 만들지** — 규칙은 `project_return_export_quarantine_rule`:
   **상대국이 출국 절차를 강제할 때만** 만든다. 강제하지 않으면 '귀국 서류 준비' 대체 안내.

- **현지 수출 검역 카드·서류 4벌** — 베트남의 `vn-export-quarantine`(catalog order 155) +

  사용자에게 컨택트시트를 보여주고 고르게 할 것(만드는 법: PIL 썸네일 격자 1장 → Read).

- **캄보디아 수입허가** — GDAHP 자료는 산 동물 수입에 허가·계약을 요구하나 그 항목들이
  교역용 화물 기준. 동반 반려동물 예외가 문서로 확인되지 않음. 사례상 불필요라 카드 없음.
- **광견병 비지정지역 여부** — 4국이 한국 기준 비지정인지 미확인. 귀국 시 항체검사 요구가
  여기서 갈린다. 현재는 가이드를 따라 전부 '필요' 전제.
